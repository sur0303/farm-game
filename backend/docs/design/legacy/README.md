# Legacy 设计材料

本目录保存第 26～34 号合同形成前的历史设计。文件被移动但未删除，内容保持原貌，用于追溯方案演进、
复盘旧探针或查找曾经讨论过的背景。

这些文档可能包含已经废弃的结论，例如：

- PlayerFarmActor 或 farm-logic 单体边界；
- Tcaplus 权威、Redis 仅缓存；
- TCONND 作为默认业务接入主链；
- v0.2 FrameMeta/total_size 编码；
- 8 人同场、固定 4096 Shard；
- 与当前 Workflow、WriterClaim、Join Ready 屏障不同的实现。

维护规则：

1. 不再同步现行方案；
2. 不作为实现 Agent 的输入；
3. 不从这里复制协议、Key、错误码或状态机；
4. 需要恢复某项有效内容时，先提炼到新的现行合同并完成评审；
5. 历史文档内部链接允许保留旧路径语义，不要求持续修复。
