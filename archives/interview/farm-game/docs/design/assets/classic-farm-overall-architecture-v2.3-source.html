⑤ P1 主动副作用

mature_at 决定成熟
Persistent Scheduler 只唤醒
成熟提醒 / 好友机会通知

首个完整实现：接入与路由 → 双 Actor 与 Join → Buy / Plant / Harvest → 好友同场 / Care / Theft → 支撑模块与压测
关键设计原则
只有 PlayerActor 与 FarmActor；模块不等于微服务。
Gate 只做接入、Session、路由、背压与下行，不编排 Workflow。
普通 Player 软资产内存原子后异步回写；接受受控硬崩溃 RPO。
Farm、唯一领取、付费与跨 Actor Receipt 必须可靠持久化。
WorkflowRecord 是唯一全局进度；Actor 只保存本地 Receipt / Settlement。
业务事实与关键 Outbox 同提交；EventBus 不是唯一事实。
Presence 不是权限；Join 与偷菜/护理分别取得 Permit。
好友页批量读取 PlayerPublicProfile + FarmReadPath，不激活冷 Actor。
作物成熟由 mature_at 派生；Scheduler 属于 P1。
query-svr 内公开档案、红点、排行榜和 Feed 可重建；不拆 infosvr。
偷菜资产语义
访客：仓库增加作物；页面显示作物估值；钱包扣实际罚金。
农场主：钱包增加与访客实际扣款完全相同的金币。
一致性：Farm 先裁决份额；Workflow 依次闭合访客和农场主 PlayerActor。
故障：中途超时返回 PROCESSING，Worker 按同一 ID 恢复，不回滚偷菜事实。
